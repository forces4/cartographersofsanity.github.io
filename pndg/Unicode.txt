Rob, you’re remembering real things, but they’re getting mixed together with the way different tools behave. Let me untangle it cleanly so you can see the ground again.

Below is the straight, practical truth about BOF/EOF, Notepad++, and why your template text sometimes mutates into that bizarre <WebsiteContent_...> stuff.

🧭 1. BOF / EOF ARE REAL — but Notepad++ doesn’t use them the way you’re thinking
In programming languages (C, C++, Python, etc.):

BOF = Beginning Of File

EOF = End Of File

They’re concepts, not literal characters in the file.

There is no actual “EOF character” in modern text files.
Old DOS sometimes used Ctrl+Z as a pseudo‑EOF, but that’s ancient history.

So:
You didn’t hallucinate BOF/EOF — they’re real — but they’re not usable as markers inside a text file.

Notepad++ cannot search for “EOF” because it doesn’t exist as a character.
